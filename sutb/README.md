# SUT B - прокат обладнання

Go та PostgreSQL. Варіант 02: знижка 7% від 7 днів або 15% від 14 днів; застосовується лише більша знижка.

`RentalService` перевіряє заявку й залишок обладнання, звертається до `RentalPolicy`, обчислює суму та створює оренду. `EquipmentRepository` і `RentalRepository` працюють із PostgreSQL; створення оренди та позиції виконується в одній транзакції.

## Інтеграційні тести

Потрібна локальна тестова база PostgreSQL зі створеними таблицями. З папки `sutb` запустіть:

```sh
go test ./...
```

`Connect()` читає `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER` і `DB_PASSWORD`.
